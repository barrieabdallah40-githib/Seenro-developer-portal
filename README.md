# SEENRO Developer Portal

A separate static frontend for the future SEENRO developer portal.

## Current status

- Public information page only.
- API access is not yet available.
- Registration, projects, credentials, and usage dashboards are not implemented.
- No secrets or backend credentials belong in this repository.

## Deployment

Deploy as a separate Vercel project and configure `developers.seenrotech.com`
after the project is ready.
